Este proyecto es una aplicación web sencilla de notas que permite crear, visualizar y gestionar apuntes de forma rápida desde el navegador.

El objetivo del proyecto es practicar desarrollo frontend, manipulación del DOM y uso de almacenamiento local para persistencia de datos.

Además, el proyecto está desplegado en GitHub Pages.


🚀 Tecnologías utilizadas:
HTML5,
CSS3,
JavaScript,
LocalStorage,
Git & GitHub,
GitHub Pages.

✨ Funcionalidades:
Crear notas nuevas,
Visualizar lista de notas,
Eliminar notas,
Persistencia de datos con LocalStorage,
Interfaz sencilla y responsiva.
